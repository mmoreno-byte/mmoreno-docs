# MM Web Studio

Estudio dedicado al desarrollo de páginas web. Diseño, optimización y mantenimiento de sitios a medida.

**URL en vivo:** https://mm-web-studio.pages.dev

## Acerca de

MM Web Studio es la cara visible de mi trabajo como estudio freelance. No es un proyecto técnico aislado: es la marca bajo la que ofrezco servicios de desarrollo web a clientes reales.

Esta ficha existe en `mmoreno-docs` como tarjeta de referencia — para que cualquier persona que llegue a la documentación pueda conocer el estudio y visitarlo. La documentación técnica detallada vive en `https://mmoreno.dev` y en la propia web del estudio.

## Qué ofrece

- **Diseño web a medida** — sitios personalizados según la marca y el público del cliente
- **Optimización** — rendimiento, accesibilidad y SEO técnico
- **Mantenimiento** — actualizaciones, soporte continuo y mejoras evolutivas
- **Landing pages y portfolios** — sitios enfocados a conversión o展示 de portfolio profesional

## Stack típico

En función del proyecto:

- **Frontend:** React 19 + Vite, HTML5 / CSS3 / JavaScript vanilla
- **CMS:** Drupal (gestión de contenidos)
- **Hosting:** Cloudflare Pages, GitHub Pages
- **Despliegue:** CI/CD con GitHub Actions o Wrangler
